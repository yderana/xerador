Backend monorepo using NestJs

Nodejs: `16.20.1`

NPM: `8.19.4`

## Perparation
Please install latest [**xerador**](https://www.npmjs.com/package/@yderana/xerador)
Installation

### install from registry
```
npx @yderana/xerador
```
#### or
```
npm install -g @yderana/xerador
```

## Create Service

```
$ xerador
```
#### or

```
$ xerador --add-service -s <service-name> -m <module-name> -i
```

## Create Module

```
$ xerador
```
#### or

```
xerador --add-module -s <service-name> -m <module-name> 
```
